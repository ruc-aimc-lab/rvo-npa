# RVO-NPA

RVO-NPA is a paired OCTA–CFP dataset with cross-modally registered non-perfusion annotations in retinal vein occlusion.

## Dataset Download


Research on the RVO-NPA dataset is currently under peer review. The dataset will be made publicly available once the work is published. In the meantime, if you are interested in cross-modal fundus image registration, we have a smaller-scale dataset, [OCTA60](https://github.com/ruc-aimc-lab/OCTA60), available for research purposes.


## Technical Details

+ OCTA to wild-field CFP registration is performed by [CARe](https://github.com/ruc-aimc-lab/care).
