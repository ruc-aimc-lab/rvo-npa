# RVO-NPA

RVO-NPA is a paired OCTA–CFP dataset with cross-modally registered non-perfusion annotations in retinal vein occlusion.

## Dataset Download

The RVO-NPA dataset is freely available upon request and for **research purposes** only. Please submit your request through this [Google Form](https://forms.gle/ETF6dE3kMsKdmggY8). Please note that the review process may take a few business days.
